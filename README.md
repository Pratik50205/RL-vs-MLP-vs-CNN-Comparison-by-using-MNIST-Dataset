# MNIST Classification: RL vs CNN vs MLP

## Overview
This project compares **Reinforcement Learning (DQN)** with **CNN** and **MLP** on the MNIST handwritten digit dataset. The goal is to understand how different learning approaches perform on the same classification task.


## Models Used
- CNN (Convolutional Neural Network)
- MLP (Neural Network)
- DQN (Reinforcement Learning)


## Dataset
- MNIST (handwritten digits 0–9)
- Loaded using TensorFlow/Keras


## Results (approx)
- CNN: ~98% accuracy  
- MLP: ~90–95% accuracy  
- DQN: ~60–80% accuracy  


## Key Point
CNN performs best for image classification, while RL is better suited for decision-making problems.
